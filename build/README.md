# build/ - Arduino 作業用一式 (UNO前提)

アーカイブ(`arc/`)は触らない。実機へ書き込むスケッチと配線手順はここに集約する。
詳細設計は `docs/DESIGN.md` 参照。

## ファイル構成

| スケッチ | 書き込む対象 | 用途 |
|----------|--------------|------|
| `ir_beep/ir_beep.ino` | 受信側UNO | 最小構成: 何かIRが来たらブザーが鳴る(配線確認用・ライブラリ不要) |
| `ir_dump/ir_dump.ino` | 受信側UNO | Phase 0: 市販リモコンの信号を解析してアドレス/コマンドを表示 |
| `ir_rx/ir_rx.ino` | 受信側UNO | 的(装着ユニット): 被弾判定・HP管理・ブザー/LED/振動演出 |
| `ir_tx/ir_tx.ino` | 送信側UNO | 銃: NECでID付きの弾を発射(自作銃フェーズ) |

## ピン割り当て表

### 受信機(的) - ir_dump / ir_rx 共通

| ピン | 信号 | 接続先 |
|------|------|--------|
| D2 | 受光モジュール OUT | VS1838B/OSRB38C9AAのOUT。**複数個は直接束ねてD2に1本**(オープンコレクタ出力・ワイヤードOR) |
| D5 | 被弾/死亡LED | LED(+) → 330Ω → GND |
| D6 | 振動モーター | 1kΩ → 2N2222ベース。モーターは5V→コレクタ、エミッタ→GND。**並列にフライホイールダイオード必須**(省略するなら未接続でOK) |
| D8 | アクティブブザー(+) | ブザー(-) → GND。**5Vアクティブ式のみ直結可。tone()/パッシブブザーは使わない**(Timer2がIRremoteと競合) |
| 5V | 受光モジュール VCC | 各モジュールのVCC-GND間に 4.7µF (素の受光部なら100Ω+VCC側に入れる) |
| GND | 共通 | 全部品共通 |

### 送信機(銃) - ir_tx

| ピン | 信号 | 接続先 |
|------|------|--------|
| D2 | トリガーSW | SW → GND (INPUT_PULLUP、押すとLOW) |
| D3 | IR送信出力 | **IRremote規定ピン・変更不可**。1kΩ → 2N2222ベース → IR LED×2直列駆動 |
| D4 | リロードSW | SW → GND (INPUT_PULLUP) |
| D5 | 発射LED(赤) | LED(+) → 330Ω → GND |
| D6 | 残弾LED(緑) | LED(+) → 330Ω → GND |
| D8 | アクティブブザー(+) | 同上 |
| 5V | IR LED駆動 | 5V → 10Ω(1/2W) → IR LED1 → IR LED2 → 2N2222コレクタ |
| VIN/GND | 電源 | 5V系(モバイルバッテリー/単3×4) |

### 送信側のLED駆動回路 (D3まわり)

```
5V ──[10Ω]── IR LED1(A→K)── IR LED2(A→K)──[C:2N2222]── E ── GND
D3 ──[1kΩ]── B:2N2222
```

※ MCUピンからIR LEDを直駆動しない(数十〜100mA必要なので必ずトランジスタ経由)。

## 作り方・手順

1. **ライブラリ導入**: Arduino IDE → ライブラリマネージャ → `IRremote` (Armin Joachimsmeyer版, v4.x) をインストール。Boardは「Arduino Uno」。
2. **Phase 0 - リモコン解析**: 受信側だけブレッドボードで組み(受光モジュール1個+D2)、`ir_dump.ino` を書き込み → シリアルモニタ115200でリモコンのボタンを押す → `Protocol / Address / Command` が出る。
3. **MVP化**: 出た `Address / Command` を `ir_rx.ino` の `GUN_ADDRESS` / `GUN_COMMAND` に書き込んで書き直し。
4. **被弾テスト**: そのリモコンの対象ボタンを撃つと HP が 5→0 に減り、ブザー+LED+振動が出て、0 で死亡(LED点灯維持)。被弾後3秒は無敵。
5. **自作銃(後で)**: `ir_tx.ino` を別UNOに書き込み、トリガーで `magic+team+player` 付きNECを発射。受信側は `MAGIC` と `MY_TEAM` が一致していれば被弾扱い(味方は無効)。

## チェックポイント

- 受光モジュールの**ピン順は品番ごとに違う**。データシートで OUT/GND/VCC を確認してから挿す(逆接続で壊れる)
- NECのリピートフレーム(長押し)はIRremoteが吸収するので連打=連射でOK
- ブザーを直結するのは消費電流20mA以下の圧電アクティブ式のみ。モーターは必ずトランジスタ
- 受光部が複数になったら、1個ずつ増やして毎回被弾確認する(配線ミス切り分け用)

# 文化祭用 電子銃 + 被弾判定 仕様書 v1.0
— 教室サイズで遊べる IRレーザータグ / LaserX互換方式 —

最終更新: 2026-09-22 / 対象: 2026Bunkasai / ステータス: 計画確定・試作前

## 0. 結論: 何を作るか

レーザー(可視光)は使わない。赤外線(IR 940nm, 38kHz変調)で撃ち合う。
理由: 文化祭で目に入っても安全、部品が安い、LaserX / DuinoTag / LZRTag と同じ方式で実績が多い。

セット = 送信機(銃) + 受信機(体・頭) が1人分。最低2セットで対戦成立。

```
[トリガー]→[MCU]→[Tr駆動]→[IR LED + レンズ] ～～～空気(5-10m)～～～ [IR受信モジュール]→[MCU]→[ブザー+LEDで被弾表示]
```

方式: MilesTag / NEC系プロトコル互換。`IRremote`ライブラリで送受信。
銃ID・チームIDを信号に載せるので「誰が誰に当てたか」が判定できる。

## 1. 構成案: 2段階で作る

教室出展・短納期を考えて2段階にする。まず v1 を全丁分作る。余裕があれば v2。

### v1 最小構成 (推奨・まずこれ)
- MCU: Arduino Nano Every互換 ×1 /丁 + ×1 /受信機
- 判定は各受信機が自立判定(ブザー+LED)。無線集計なし。
- 配線・コードがDuinoTag / Sand1929とほぼ同じ。作例が多くデバッグしやすい。
- 1人分 ≈ 3500〜5000円。2人分で7000〜10000円。

### v2 拡張 (余裕があれば)
- MCUを ESP32 (XIAO ESP32C3 / M5StickC Plus) に置換
- LZRTag方式: MQTT + Raspberry Pi / PC集計サーバでスコア・リスポーン管理
- 効果音 I2S + WS2812演出、ビーコン(旗・安全地帯)が追加できる
- v1のIR送受信部はそのまま流用できるので作り直しにならない。

> 今回の3Dモデル(`2026Bunkasai_gun.stl`)は v1/v2 どちらも収まる寸法で設計する。

## 2. 部品選定 (1人分 = 銃1丁 + 受信1セット)

すべて秋月・千石・スイッチサイエンス・Amazonで買える汎用品。代替も書く。

### 2.1 銃側 (送信機)
| # | 部品 | 推奨型番 | 数量/丁 | 役割・選定理由 | 代替・注意 |
|---|------|----------|---------|----------------|------------|
| TX-MCU | Arduino Nano Every互換 / Nano V3 | ATmega328P 5V | 1 | 資料が最多。IRremote動作実績◎ | ESP32化はv2で。3.3V化時はTr回路要調整 |
| TX-IR | 高出力IR LED 940nm 狭角 | TSAL6100 (Vishay, ±10°) | 2 | 到達距離の要。2直列で直進性UP | OSRAM SFH4550も可。940nmに統一 |
| TX-Tr | NPN Tr / N-FET | 2N2222 / 2SC1815 / IRLML2502 | 1 | MCUピンでは電流不足なので増幅。100mA級を流す | FETの方が発熱少。Gate抵抗1k |
| TX-R | 金属皮膜抵抗 | 10Ω 1/2W (LED制限), 1k (ベース) | 各1-2 | LED電流制限 | 電流は (Vcc-Vf×2)/R で計算 |
| LENS | 凸レンズ Ø25mm f≈25-30mm | VRゴーグル用 / アクリル | 1 | ビーム絞り。これが無いと5m届かない | DuinoTagはライトガンのレンズ流用。100均虫眼鏡でも可 |
| SW-T | タクト/マイクロSW (トリガー) | オムロン B3F等 + レバー | 1 | 引き金 | チャタリングはソフトで除去 |
| SW-R | リロード・電源スライドSW | SS-12D00等 | 各1 | リロード・電源 | — |
| LED-T | 可視光演出LED 赤+緑 5mm | 30mA級高輝度 | 2 | 発射フラッシュ・残弾表示 | 銃口に赤を入れると当て感UP |
| BZ-T | 圧電ブザー アクティブ5V | PKM22等 | 1 | 発射音・空撃ち音 | パッシブ+NewToneで音階も可 |
| BAT-T | 電源 | 単3NiMH×4 or 18650×1+保護基板 or モバイルBT | 1式 | 5V系が楽。教室はUSB給電が安全 | Li-Poは保護回路必須。文化祭はNiMH推奨 |

### 2.2 被弾判定側 (受信機・体に付ける)
| # | 部品 | 推奨型番 | 数量/人 | 役割・選定理由 | 代替・注意 |
|---|------|----------|---------|----------------|------------|
| RX-S | IR受信モジュール 38kHz | VS1838B / TSOP38238 / TSOP34438 | 3-4 | 38kHz復調済。100円で買える要 | 受光面を外向け。デカップC 4.7uF+100Ω必須 |
| RX-MCU | Arduino Nano Every互換 | TXと共通化 | 1 | 在庫・予備を共通化できる | 体側と銃側でFWだけ変える |
| RX-LED | 被弾表示LED / テープ | WS2812B ×1 or 赤緑LED×2 | 1式 | 当たったら赤点滅、復活で緑 | WS2812は1ピンで派手。電源注意 |
| RX-BZ | 圧電ブザー | 同上 | 1 | 被弾音 | うるさい会場は振動モータ追加も有 |
| HAT | 頭+胸マウント | ヘアバンド / ヘルメット / ベスト + 小基板 | 1式 | 前・後・銃の3点受光がDuinoTag定番 | ダイソー品でOK。受光窓は黒筒で指向性UP |
| BAT-R | 電源 | 単3×3 / USBモバイル | 1式 | TXと共通化 | ケーブル抜け対策にコネクタ固定 |

### 2.3 共通・消耗品
- ブレッドボード→ユニバーサル基板、ジャンパ線、収縮チューブ、M3ネジ(10mm×6, 5mm×4)、スペーサ
- PLAフィラメント (銃筐体用、現行STLで約200g/丁)
- 100均改造用おもちゃ銃 (筐体自作が間に合わない時の保険。DuinoTag推奨ルート)

チーム分けスイッチ(2bit DIP)があると4チーム対戦ができて文化祭受けが良い。1丁+50円。

## 3. 電気設計

### 3.1 配線 (銃側・Nano例)
```
5V ──[10Ω]── IR LED1(A)── IR LED2(A→K)──[C:2N2222]──GND
D3 (IRsend PWM) ─[1k]── B:2N2222, E:GND
D2 ← トリガーSW ← GND (INPUT_PULLUP)
D4 ← リロードSW ← GND
D5 → 可視LED(赤) →330Ω→GND
D6 → 可視LED(緑) →330Ω→GND
D8 → ブザー(+) , GND→ブザー(-)
VIN ← 5V系電源, GND共通
```

### 3.2 配線 (受信側・Nano例)
```
D2 ← VS1838B OUT (前), VCC→5V, GND→GND, VCC-GND間に4.7uF
D3 ← VS1838B OUT (後)
D4 ← VS1838B OUT (銃)
D6 → WS2812 DIN (別5V給電, 330Ω直列推奨)
D8 → ブザー
D9-D10 ← チームDIP SW
```

受信3個はOR判定でOK。`IRrecv`は1ピンしか受信できないので、3個のOUTをダイオードORか、順番にポーリングする。簡単なのは「前」をメイン、`loop()`で切替。v2 ESP32ならRMTで多ch受信も可。

### 3.3 信号フォーマット
- 38kHzキャリア、NECライク: `[チーム2bit + プレイヤー6bit + ダメージ8bit + CRC]`
- ライブラリ: `Arduino-IRremote` (z3t0版) + `NewTone` (Sand1929方式)
- 発射: D3から `IrSender.sendNEC(addr, cmd)` を1発70ms間隔で3連射すると教室でも当たりやすい
- 被弾: 受信側でaddr/cmdをデコード→自チーム無視→HP減算→3秒無敵→0で死亡演出

互換性: LaserX市販品との混戦は非推奨(プロトコル非公開のため)。自作同士で統一する。

## 4. 3Dモデル連携 (現行STLとの対応)

現行: `2026Bunkasai_gun.stl` 単一中空ボディ (barrel Ø80/Ø72 ×120mm + grip 55mm)。
このままでは基板が入らないので次リビジョンでこう割る:

- [ ] barrelを左右2分割 + 上蓋スライド式 (電池交換口)。内壁にM3ボス×4、基板スペーサ
- [ ] 先端 Ø25レンズホルダーリング + IR LED×2固定座 (光軸+z)。ズレると5m届かない
- [ ] 受光窓: 銃上部にVS1838B用スリット×1 (黒筒Ø8深さ10で指向性)
- [ ] トリガー穴 12×20mm + マイクロSW座、グリップ内に配線ダクト幅6mm
- [ ] 胸ターゲット別パーツ: Ø60円盤 + VS1838B×1 + WS2812窓 (ヘアバンドに結束)
- [ ] 公差: はめ合い0.3mm、ネジ下穴Ø2.6、サポート45°以下になる向きで分割

現行STLは外形モックとして印刷可。電装入り試作は次版`gen_stl4.py`で対応。先にダンボール+ブレッドボードで回路成立を確認してから筐体を彫る順番が早い。

## 6. 組立・テスト手順

1. ブレッドボードでTX→RX直結テスト (レンズ無し30cmでNEC受信確認、シリアルでaddr表示)
2. Tr駆動+IR2直列で5mテスト (教室の蛍光灯下で誤動作ないか確認。直射日光はNG)
3. レンズ装着で10mテスト。当たらない→LED電流・光軸・レンズ焦点を調整
4. トリガー・ブザー・LED演出をFWに統合。残弾5→リロード3秒のルール実装
5. ヘアバンド受信3点化。前後+銃で死角を消す。黒筒で自銃の跳ね返り誤検出を防止
6. ダンボール筐体で1日運用テスト (落としても壊れないか、電池持ち2時間か)
7. 3D筐体印刷→電装移設→ネジ止め→再テスト。割れたら infill 30%・壁3周に上げる
8. 当日運用: 受付でチーム分岐、HP5・リスポーン10秒、審判1名。予備電池・予備丁必須

## 7. 当日ゲームルール案 (会議室向け)
- 2vs2、各HP5、1被弾1ダメージ、3秒無敵、0で死亡赤点滅、味方撃ち無効
- リスポーンは自陣タッチで復活。制限時間3分、残HP合計で勝敗
- 安全: 銃口を顔に向けない、可視レーザー禁止、走らない、受付で動作説明30秒
